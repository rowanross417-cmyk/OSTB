how to use
------------------
1. download it 
   
i. how to install \
navigate to [Releases](https://github.com/rowanross417-cmyk/OSTB/releases) \
if on windows... install OSTB-win-x64.zip \
if on linux... install OSTB-linux-x64.tar.gz \
if on macos... install OSTB-macOS-x64.zip 

ii. extract the file \
you have a zipped file, now extract it

iii. locate the program
on windows, run OSTB.exe
on linux and macos, run OSTB


2. using the program 
   
i. the time bank \
the time bank functions as follows.. \
on the left, there is a stopwatch. the idea is that you track the time you spend doing something important like study, work, or general obligations \
in the middle, you have a button to "convert" the time you spend working into "banked time."
> on converting \
> there is an input for "Duration (Min.):" and "Conversion Ratio:".
  Duration is the amount of time it takes to convert 100% of your earned time into banked time, and this can be adjusted to suit your needs. \
  the conversion ratio is how much earned time is converted into banked time, \
  e.g. a ratio of 1.0 would convert 1 minute of earned time into 1 minute of banked time, \
> a ratio of 2.0 would convert 1 minute of earned time into 2 minutes of banked time, \
> and a ratio of 0.5 would convert 1 minute of earned time into 30 seconds of banked time. \

on the right is your "banked time." this functions just like a timer. \
an example use case: one might accumulate 30 minutes of banked time, open minecraft, and click the button to start claiming, and then stop playing when the timer runs out.

ii. the notepad \
at the bottom of the program, there is a bar with tabs. the one you start on is the time bank, labelled "TB." \
the next tab is 'NP." this is a notepad. you may use it to write your notes, or something i guess

iii. the calendar \
this is the "Cal" tab. it is a calendar. you can click on the boxes and type in reminders and such for any particular day. \

iv. the settings \
this is the "Sett." tab. it contains settings for the program.
> the "always on top" setting, when turned on, keeps the program "on top" of any other programs even when you click off of it. \
> the fullscreen toggle toggles fullscreen \
> the UI scale adjuster is used to adjust the UI scale \
> the notepad font setting allows you to adjust the font size of the notepad text, in case you have a particular taste for notepad font sizes.

and thats it! happy... banking. and note-taking. and calendaring.
